### Introduction

Thank you for installing my mod. Gojo is a 9B SSF2 mod, however I have included versions that work with 9B FMC and Beta FMC. Showcasing and including this mod into modpacks is fine, as long as you credit me (ComicalTNM or Extinctive) in the video description/modpack credits. Claiming this mod as your own creation is not allowed and I will take actions to take down the video if that is the case.



### Mod Disclaimers

Shinjuku Gojo, which is Gojo's third form, will be a bit buggy on first use as the game has to load in the character. To circumvent this, go into training mod and reach the conditions to activate Shinjuku Gojo, and use his final chant side B variant, which is max blue. This allows the game to load the character into it's memory, so it won't have any issues loading in the character the next time you use him.



### Vanilla 9B Version

To use Gojo in vanilla 9B, just replace the DAT67.ssf file included in this folder and paste it into the data folder of your 9B SSF2 build. Gojo replaces Naruto, so if you want to play him, choose Naruto.



### 9B FMC Version

The 9B FMC version of Gojo has his statName and linkage\_id as "gojo" and his GUID as null. When you add the character into 9B FMC, use those values for the name and GUID respectively. Gojo's second form, the form where his blind fold is off, has an issue with the final smash in 9B FMC. Because 9B FMC was built with a 32-bit architecture, the game runs out of memory when the cinematic final smash is playing. Unfortunately there is no definitive fix for this. Avoid using Serious Gojo's final smash to prevent the game from crashing.



### Beta FMC Version

The beta FMC version of Gojo also has his statName and linkage\_id as "gojo" and his GUID as null. When you add the character into beta FMC, use those values for the name and GUID respectively. Unfortunately, the beta FMC version has the same issue as the 9B FMC version when it comes to Serious Gojo's final smash. The current version of beta FMC is built on a 32-bit architecture, so the game will still run out of memory when the cinematic final smash is used. However, the creator of FMC, Jotardo, is currently working on a 64-bit architecture version of FMC for the latest SSF2 version. This project is still in progress however, and Jotardo is busy with things in his life, so it might be a while before it is released to the public. Please be patient and bear with the current version of beta FMC for the time being.
